# 現場小主機安裝說明（0.4 版起）

現場小主機是放在社區（或公司）的一台電腦，負責：
- 接 PSC 平台的指令，去操作攝影機（白名單、參數、照片、重開機）。
- 接收攝影機的辨識推送，把進出紀錄送到平台。

## 1. 放檔案

1. 在電腦上建一個資料夾，例如 `C:\PSC-Gateway`。**不要放在桌面、下載或「使用者」資料夾**，那些位置不能設定開機自動執行。
2. 把這兩個檔案放進去：
   - `現場小主機.exe`
   - `gateway_config.json`：在 PSC 網頁「場站」→「新增小主機」下載；**cameras 裡的 IP 要改成現場攝影機的 IP**。
3. 點兩下 `現場小主機.exe`。看到「已連上平台」就成功了。
   - 第一次執行如果 Windows 防火牆跳出提示，請按「**允許**」，並勾選「私人網路」。這是為了讓攝影機能把辨識結果推給這台電腦。

## 2. 攝影機設定推送（即時進出紀錄要用）

到攝影機後台「HTTP POST」分頁設定：

| 欄位 | 要填的內容 |
|---|---|
| 打開 HTTP POST 功能 | 勾選 |
| 伺服器 IP、PORT、路徑 | `小主機電腦的 IP:8080/api/lpr/notify`，例如 `192.168.1.207:8080/api/lpr/notify` |
| 工作模式 | 模式5 |
| 發送完整圖 | 勾選（非白名單車要存照片） |
| SSL 連線 | **不要勾** |
| 入口自動開門 | **不要勾**：開閘由攝影機自己的白名單決定，小主機絕不下開閘指令 |
| 上傳週期 | 10 秒 |

設定好之後，到 PSC 的場站頁面，攝影機旁邊會顯示「● 推送中」。

⚠️ 小主機電腦的 IP 要固定，可以在路由器綁定，或手動設定 IP。不然 IP 變了，攝影機就推不過來。

## 3. 開機自動執行（建議）

在小主機的黑色視窗輸入 `I`，再按 Enter，然後在 Windows 跳出的確認視窗按「是」。
- 之後電腦開機就會自己在背景執行，不用開黑色視窗，也不用登入 Windows。
- 訊息會記在資料夾裡的 `gateway_log.txt`（背景版不記車牌）。
- 資料夾會被設定成只有系統管理員能修改，用來保護裡面的通行碼。之後要改設定檔，要用系統管理員身分。
- 要取消：再點兩下 `現場小主機.exe`，畫面會說「已經有一個在跑」，這時輸入 `U` 再按 Enter。

## 4. 安全注意

- `gateway_config.json` 裡的 token 等於這台小主機的鑰匙，不要外流。外流了就到 PSC 場站頁按「重發通行碼」。
- 攝影機的白名單（8117 埠）和設定頁都**不用密碼**，所以攝影機和小主機要放在跟住戶網路**隔開**的網段。
